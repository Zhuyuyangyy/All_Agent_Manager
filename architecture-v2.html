EventBus 事件类型

  • task.* — 任务生命周期：started, completed, failed, timeout, cancelled, retrying
  • agent.* — Agent 状态：health_changed, recovery_triggered, status_updated
  • skill.* — 技能事件：activated, disabled, extracted, matched
  • review.* — 审查事件：approved, rejected, needs_info, auto_approved
  • plugin.* — 插件事件：registered, enabled, disabled, capability_added
  • system.* — 系统事件：startup, shutdown, config_changed

TaskRegistry 类型处理器

  • http_task — HTTP Worker 任务（OpenClaw, OpenHanako）
  • cli_task — CLI Worker 任务（Hermes）
  • discovery_task — 智能发现任务
  • replay_task — 复刻分析任务
  • health_check — 健康检查任务
  • 支持动态注册新类型，运行时添加 handler

插件贡献能力

  • skills/ — 贡献技能模板（Markdown SKILL.md）
  • agents/ — 贡献 Agent 模板（JSON 配置）
  • commands/ — 贡献用户命令（斜杠触发）
  • routes/ — 贡献 HTTP 路由（需 full-access）
  • providers/ — 贡献 LLM Provider
  • 插件通过 EventBus 注册能力，发布能力变更事件

多 Agent 并行改进

  • Worker Pool — 控制并发数，避免资源耗尽
  • 非阻塞调度 — Dispatcher 不等待 Worker 完成
  • Hermes busy-file — 保留现有保护机制
  • asyncio.gather — 多任务真正并行执行
  • 资源限制 — CPU/内存/网络配额
  • 优先级队列 — 高优先级任务优先执行
